# 📖 Chronicles

> *Adventure. Mystery. Choice. Friendship. Legacy.*

Chronicles is an interactive fantasy adventure currently in development.

Players journey alongside **Pip**, a curious woodland chronicler who remembers conversations, records important moments, and searches the Great Library to uncover the history, legends and secrets of the world.

---

# ✨ Current Features

## 🐿️ Pip

- Conversational companion
- Player memory
- Chronicle journal
- Social interactions

## 📚 The Great Library

- Searches lore books
- Finds the correct book automatically
- Reads individual sections
- Supports aliases and natural input
- Markdown-powered lore system

# ❤️ About Pip

Pip isn't an AI assistant.

He's a character.

A woodland chronicler who follows the player's journey, remembers their story, and eagerly searches the Great Library whenever knowledge is needed.

Every feature added to Pip is designed to make him feel less like software and more like a travelling companion.
